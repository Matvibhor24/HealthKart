7. use jsonwebtoken to authorize
    set up jwt_user as a middleware. It first checks if header is 'Authorize' and token value is present.
    Then inside post request, create a payload object using user id and sign that for creating a jwt token for that.
    [jwt.sign(payload,process.env.jwtUserSecret,{
            expiresIn: 360000
        }, (err,token)=>{
            if (err) throw err;
            res.status(200).json({
                succes: true,
                token: token
            });
        });]

    whn using the get request, use the middleware along with it.
    pass the token along with request, if User.finById(req.user.id) is there, res.json (user);

    So, for a user we first generate a token and then using that token we can get the user details. If it fails in the middleware ,
    it gives 401 error.
